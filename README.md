# SENAI HUB TECH TOOLS — V8 React

Correção da navegação lateral: todas as nove opções abrem uma seção própria. Início e Ferramentas oferecem catálogo, Downloads permite exportar JSON e Suporte contém instruções. Cursos, Trilhas, Laboratórios, Simuladores e Projetos exibem páginas preparadas com estado vazio (sem inventar dados).

## Execução
```bash
npm install
npm run dev
```
Para publicar na Vercel: Framework Vite; build `npm run build`; output `dist`.

**Atenção:** administração ainda demonstrativa, salva em localStorage, sem Firebase e sem controle de acesso real. Não usar como painel seguro em produção.
